# 배치 구조 및 수집 전략

> 배치는 매일 06:00 실행되며, 수집 → 브리핑 생성 → 준비 카드 갱신 순서로 동작한다.

---

## 실행 흐름

```
cron: 0 6 * * *  →  python batch/run.py

Step 1. collect_news.py      → 구독 기업 뉴스 수집
Step 2. collect_jobs.py      → 구독 기업 채용공고 수집
Step 3. generate_briefing.py → 유저별 오늘 브리핑 생성
Step 4. generate_prep.py     → 기업별 준비 카드 스냅샷 갱신

오류 처리 원칙:
  - 특정 기업 수집 실패 → 건너뛰고 다음 기업 진행
  - 특정 유저 브리핑 실패 → 건너뛰고 다음 유저 진행
  - 모든 실패: batch/logs/YYYY-MM-DD.log 기록
  - 슬랙/이메일 알림: Phase 4
```

## 기업 유형별 수집 전략

### 대기업 (large)

```
뉴스:
  - 네이버 뉴스 검색 API: "{기업명}"
  - 출처 필터: 경제지 우선 (한국경제, 매일경제, 조선비즈)
  - 동일 제목 유사도 85%+ 중복 제거
  - 수집 범위: 최근 24시간, 최대 5건

채용공고:
  1순위: 공식 채용사이트 RSS/API (기업별 URL 목록)
  2순위: 사람인 API (공식 사이트 장애 시)

준비 카드 재료:
  - 채용공고 "지원자격/우대사항" 텍스트 기반
  - companies.description + 채용공고 기반 인재상 요약
```

### 중견기업 (mid)

```
뉴스:
  - 네이버 뉴스 검색 API: "{기업명}" + "{기업명} 채용"
  - 결과 3건 미만 시 스킵 (노이즈 방지)

채용공고:
  1순위: 사람인 API
  2순위: 잡코리아 API
  공식 채용페이지 있는 기업: URL 별도 등록 관리

준비 카드 재료:
  - 채용공고 텍스트 기반
  - 인재상 없으면 "채용공고 기반 추정" 명시
```

### 공기업 (public)

```
뉴스:
  - 네이버 뉴스 검색 API: "{기관명}" + "{기관명} 사업/정책"
  - press_url 있는 기관: 보도자료 페이지 추가 수집

채용공고:  → 아래 Fallback 전략 참조

준비 카드 재료:
  - 채용공고 "직무소개/지원자격" 텍스트 기반
  - 공식 채용공고 원문 URL 직접 링크
```

## 공기업 채용공고 수집 Fallback 전략

### 수집 우선순위

| 순위 | 소스 | 커버리지 | 장점 | 한계 | 사용 조건 |
|------|------|----------|------|------|-----------|
| **1** | 공공데이터포털 채용공고 API | 중앙부처 산하 공공기관 중심 | 구조화된 데이터, 공식 출처 | 소규모 지방공기업 누락 가능, 응답 지연 | 항상 1순위 시도 |
| **2** | 기관 공식 채용페이지 | 개별 기관 100% | 정확도 최고, 원문 직접 | 기관마다 URL/구조 다름, 파싱 유지보수 필요 | 공공데이터 미커버 기관 |
| **3** | 사람인 API | 공기업 포함 다수 | 구조 통일, API 안정적 | 공고 등록 지연, 일부 누락 | 1+2 모두 실패 시 |
| **4** | 수동 등록 | 100% | 정확도 보장 | 운영 부담 | 주요 공기업 초기 시드 |

### 예외 케이스 처리

| 케이스 | 처리 방식 |
|--------|-----------|
| 공공데이터 API 타임아웃 | 기관 공식 채용페이지 → 사람인 순 fallback |
| 기관 공식 채용페이지 파싱 실패 | 사람인 API fallback + 오류 로그 기록 |
| 공공데이터 API에 기관 미등록 | website_url + "/recruit" 경로 시도 |
| 모든 소스 수집 실패 | 해당 기업 스킵 + "수집 실패 기관" 로그 기록 |
| 마감일 지난 공고 재수집 | is_active = FALSE 처리 (삭제 아님) |

### 수집기 코드 구조

```python
# batch/sources/public_corp.py

class PublicCorpCollector(BaseCollector):
    def collect_jobs(self, company: Company) -> list[JobPostingCreate]:
        # 1순위: 공공데이터포털 API
        results = self._try_public_data_api(company)
        if results:
            return results

        # 2순위: 기관 공식 채용페이지
        if company.website_url:
            results = self._try_official_site(company)
        if results:
            return results

        # 3순위: 사람인 API fallback
        results = self._try_saramin_api(company)
        if results:
            return results

        # 모두 실패
        logger.warning(f"[수집 실패] company_id={company.id}, name={company.name}")
        return []
```
